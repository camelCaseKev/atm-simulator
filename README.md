# atm-simulator
A simple ATM simulator created as part of my final project for a Game Development and Object Oriented Programming course at Lake Superior College.


***Language:*** C#  
***GUI:*** Windows Forms  
***Features:*** Logging in, logging out, viewing account balances, viewing recent transactions, making deposits and withdrawals, as well as viewing all accounts and their respective balances with the master account.

***NOTE: Demo login information can be found in README.txt.***
